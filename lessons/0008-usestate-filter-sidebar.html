useState — the filter sidebar comes alive

Props flow down from a parent. State is data a component owns and can change over time — a toggle flipped, a chip selected, a luggage count stepped up. That is what makes the sidebar feel alive.

Mission tie-in: side-project task 0007. Your Emotion cards already look like results. The filter sidebar on the target screenshot must respond to clicks. Today each control keeps its own state. Making those clicks actually filter the list is the next lesson (lift state) — do not skip ahead.

The one idea

State is memory that survives a re-render because you asked React to keep it. A normal variable resets every time the function runs. useState returns a value React remembers, plus a setter that schedules an update and re-runs the component with the new value. (react.dev — useState.) 
import { useState } from "react";

function FilterToggle() {
  const [on, setOn] = useState(false);

  return (
    <button type="button" onClick={() => setOn(!on)}>
      Free Cancellation: {on ? "On" : "Off"}
    </button>
  );
}

Read the line left to right:

  • useState(false) — start with false on the first render.
  • on — the current value (this render).
  • setOn — call this to change it; React re-renders.

Three shapes you'll use in the sidebar

Control State type Typical update
Free Cancellation toggle boolean setOn(!on)
Service / class chips string | null or a Set-like array select / deselect a key
Luggage stepper number setCount(count + 1)

Emotion from lesson 0005 still applies: a chip can take an active prop driven by state — <Chip active={selected === "meet-greet"}>. State decides; styled components display.

Hard boundary (do not blur this)

Local state only changes that component's UI. Flipping Free Cancellation in FilterToggle does not hide vehicles in the list — the list cannot see that state. Shared filter → results wiring is lifting state up (side-project task 0008). If you try to reach into the list from a child today, you're inventing the next lesson early and usually getting it wrong.
