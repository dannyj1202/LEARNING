Vehicle page component map

Compressed view of how the Almosafer-style results UI splits into React components. Revisit while building.

Tree

ResultsPage
SiteHeader — brand, currency, language, auth (out of scope polish)
SearchSummary — route · datetime · passengers · “Book another ride”
FiltersPanel
FilterToggle — Free Cancellation
FilterChip — services / class / type
PriceRange
LuggageStepper
ResultsList
SortSelect
VehicleCard × N
image · title · models · capacity · features · price · BookNowButton

Split heuristics

  • Repeats with different data → one component (VehicleCard, FilterChip)
  • Independent interaction → own component (LuggageStepper, FilterToggle)
  • Page layout regions → container components (FiltersPanel, ResultsList)
